# Bots vs Drones

A browser-based 3D auto-battler. Ground bots against flying drones: each round
both commanders spend a budget on units, commit blind, then watch the fight.
You never control a unit directly, only what to buy, stance, target priority,
and how smart your units are.

## Play

Open `game.html` in a browser. It's a single file; three.js loads from a CDN,
so no build step or install is needed.
